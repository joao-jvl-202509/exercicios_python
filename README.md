## Descrição

Este repositório contém 25 exercícios desenvolvidos durante as aulas de Python. Os exercícios têm como objetivo praticar conceitos básicos de programação, como variáveis, entrada e saída de dados, estruturas condicionais, estruturas de repetição e cálculos.

## Tecnologia utilizada

* Linguagem: Python
* Versão: Python 3.x.x

Para verificar a versão do Python instalada no computador, utilize:

python --version

## Como executar

### 1. Instalar o Python

Caso o Python ainda não esteja instalado, faça o download pelo site oficial:

https://www.python.org/

### 2. Baixar o repositório

Clone este repositório utilizando o Git:

git clone url_do_repositorio

Depois, entre na pasta:

cd exercicios_python

### 3. Executar um exercício

Para executar um exercício específico, utilize o comando:

python nome_do_arquivo.py

Por exemplo:

python exercicio01.py

Cada exercício pode ser executado separadamente.
